# dev-env-config

The configuration repository for running ClusterKeep locally with [common-dev-env](https://github.com/LandRegistry/common-dev-env). `configuration.yml` lists every app and checks out its `development` branch.

Setup steps are in the [organisation README](https://github.com/ha-private-cloud/.github/blob/main/profile/README.md#running-it-locally).
